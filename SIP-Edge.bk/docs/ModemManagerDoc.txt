# ModemManager API Documentation (Partial)

## Overview
ModemManager is a D-Bus service for managing mobile broadband (MBIM, QMI, AT) devices.

## Key D-Bus Interfaces

### 1. Manager (`org.freedesktop.ModemManager1`)
Main entry point for the service.
- **Location**: `/org/freedesktop/ModemManager1`
- **Methods**:
  - `GetDevices()`: Returns list of device paths.
  - `GetModems()`: Returns list of modem paths.

### 2. Modem (`org.freedesktop.ModemManager1.Modem`)
Represents a modem device.
- **Properties**:
  - `State` (enum): Current state (Initializing, Enabled, Disabling, Disabled).
  - `StateFailedReason` (enum): Reason if State = Disabled.
  - `Bearers` (array): List of bearer paths.
  - `Device` (string): Path to the device object.
  - `Sim` (string): Path to the SIM object.

### 3. Bearer (`org.freedesktop.ModemManager1.Bearer`)
Represents a connection profile.
- **Properties**:
  - `Interface` (string): Network interface name.
  - `Connected` (boolean): Connection status.
  - `Allowed` (boolean): Whether this bearer is allowed to connect.
  - `Settings` (dict): Connection settings (APN, username, password).
    - Key `apn` (string): Access Point Name.
- **Methods**:
  - `Connect()`: Establish connection.
  - `Disconnect()`: Close connection.

## Common Workflow
1. Get Manager.
2. Get Devices via Manager.
3. Get Modem via Device.
4. Get Bearers via Modem.
5. Check `Connected` status in Bearer properties.
6. Use `Connect()` or `Disconnect()` if needed.

## Example Python Snippet (Conceptual)
```python
import dbus

# Get DBus proxy
m_iface = dbus.Interface(bus.get_object("org.freedesktop.ModemManager1", "/org/freedesktop/ModemManager1"), "org.freedesktop.DBus.Properties")
modem_path = m_iface.Get("org.freedesktop.ModemManager1", "Modems")[0]

b_iface = dbus.Interface(bus.get_object("org.freedesktop.ModemManager1", modem_path), "org.freedesktop.DBus.Properties")
bearers = b_iface.Get("org.freedesktop.ModemManager1.Modem", "Bearers")

# Iterate bearers and check connection
```

## Vendor-Specific Details (Quectel)
- Quectel devices often use QMI protocol.
- May need AT commands for initial setup or fallback.
- Check vendor-specific D-Bus extensions if standard interface is insufficient.
