## Decisiones tecnicas

- El backup usa `--skip-ssl` para desarrollo Docker; en EdgeBox no afecta
- phpMyAdmin se instalo con PHP built-in server (no Apache) para minimizar consumo
- Se adopto Python como herramienta de edicion de archivos para evitar corruption
  de encoding por PowerShell
